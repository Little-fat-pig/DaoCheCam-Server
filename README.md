# 倒车摄像父（DaoCheCam-Server）

> ⚠️ **本项目仅供个人学习交流使用，禁止任何商业用途。使用产生的一切后果自负，详见文末《免责声明》。**


旧手机上的倒车画面推流端。父子双 App 中的「父」：打开即横屏全屏预览，点「开始服务」后通过 HTTP 向局域网提供标准 MJPEG 视频流（`/video` 实时流、`/shot.jpg` 单帧快照），任何浏览器或查看端 App 均可直接观看。

## 功能

- 摄像头：前/后切换，Camera1 API，连续自动对焦（视频→图片→无穷远三级兜底），自动白平衡
- 分辨率：640×480 / 1280×720（默认）/ 1920×1080
- 画面旋转：0 / 90 / 180 / 270（摄像头倒装调 180°）
- 画质：中(60) / 高(80) / 最高(90)
- 30fps 封顶限流，独立压缩线程只压最新帧，低配旧手机不卡不死缓冲
- 端口 8080，被占用自动避让 8081–8085，屏幕地址条一键复制实际地址
- 前台服务常驻，CORS 全开，方便网页端直连

## 使用

1. 旧手机安装，打开即横屏预览
2. 选好摄像头/分辨率/旋转/画质
3. 点「开始服务」，屏幕显示 `http://IP:端口/video`，点击地址条复制
4. 主手机连同一 WiFi，浏览器打开该地址即可观看

## 设计思路（原创架构）

代码 100% 从零手写，无任何第三方项目代码。核心链路：

```
Camera1 预览回调（NV21）
   → 只做一次内存拷贝、立刻归还缓冲（相机缓冲永远不堵）
   → 独立压缩线程，永远只压「最新一帧」，旧帧直接丢弃（低配手机不积压不卡顿）
   → YuvImage 压成 JPEG（按需旋转，支持倒装）
   → 自写极简 HTTP 服务器（ServerSocket 手写协议，无框架）
      ├ /video     multipart/x-mixed-replace MJPEG 实时流
      └ /shot.jpg  单帧 JPEG（供网页端自动发现探测）
```

几个关键取舍：

- **不用 MediaCodec 硬编码**：MJPEG 一帧一图，浏览器 `<img>`/fetch 直接能解，兼容性最好
- **压缩与采集分离**：相机回调只 memcpy（<1ms），压缩挪到独立线程且只压最新帧——这是旧手机上"看着卡"的根治方案
- **对焦三级兜底**：CONTINUOUS_VIDEO → CONTINUOUS_PICTURE → INFINITY，老机型全兼容
- **端口自动避让**：8080 被占自动试 8081–8085，多个工具同时跑不冲突

## 构建

- 纯 Java + Camera1 API，零第三方依赖
- AGP 7.3.1 / Gradle 7.4 / JDK 17 / compileSdk 34，minSdk 24
- `gradle assembleRelease` 生成 APK，自行签名后安装

## 配套

- 查看端（录屏+录像）：DaoCheCam-Viewer「倒车摄像子」
- 网页查看页（可选）：daocheyx.html，支持自动发现本服务
